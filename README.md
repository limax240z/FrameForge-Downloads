# FrameForge – Downloads

Fertige Versionen von **FrameForge**, einem FPS-Optimierer für Windows 10 und 11 (64 Bit).

## Installieren
1. Unter [Releases](https://github.com/limax240z/FrameForge-Downloads/releases/latest) die Datei
   `FrameForge-Setup-<Version>.exe` herunterladen.
2. Doppelklicken. Zeigt Windows „Der Computer wurde durch Windows geschützt“, auf **Weitere Informationen →
   Trotzdem ausführen** klicken (das Programm ist nicht signiert).

## Updates
FrameForge sucht bei jedem Start selbst nach einer neuen Version, und auf Wunsch über
**Einstellungen → Updates → Nach Updates suchen**. Ist eine da, lädt es sie herunter, prüft sie und installiert sie
mit einem Klick auf **Jetzt aktualisieren**.

Dieses Projekt enthält nur die fertigen Programmdateien. Der Quelltext ist privat.
